Code in the game

SDL 2
Window, input, graphics and sound, by Sam Lantinga and the SDL contributors. zlib license.
stb_image, stb_image_write and stb_vorbis
Picture and Ogg Vorbis decoding, by Sean Barrett and contributors. Public domain or MIT, at your choice.
Emscripten (browser version only)
Compiles the engine to WebAssembly and supplies the loader and runtime library in the page's files. Emscripten is under the MIT and University of Illinois/NCSA licenses; its C library (musl) is MIT, and its C++ library (LLVM libc++) is Apache 2.0 with LLVM exceptions. See Emscripten's license.
Sentry Native (optional, desktop builds only)
Crash reports, off unless built with SFE_SENTRY. MIT license. Not in the browser version.
